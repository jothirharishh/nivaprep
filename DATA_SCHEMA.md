# Data Schema — BoardMate 10

This document defines the logical data model. Physical database tables and API payloads may vary, but field meanings and validation rules should remain consistent.

## 1. Identifiers and conventions
- Use stable IDs (UUIDs or equivalent opaque identifiers) for sources, passages, questions, and attempts.
- Store timestamps in UTC using ISO 8601.
- Store page numbers as one-based printed/PDF page references and, where they differ, keep both PDF page index and printed page label.
- Keep source edition metadata explicit. Never merge different editions without an intentional migration.
- Treat extracted text and LLM output as untrusted input.

## 2. Source / textbook

```json
{
  "source_id": "src_example",
  "title": "Class 10 Science",
  "subject_id": "science",
  "medium": "English",
  "board": "Tamil Nadu State Board",
  "curriculum": "Samacheer Kalvi",
  "class_level": 10,
  "edition": "edition identifier or year",
  "publisher": "publisher name",
  "source_uri": null,
  "rights_status": "review_required",
  "rights_notes": "Record permission or applicable terms",
  "file_sha256": "optional checksum",
  "ingestion_status": "pending",
  "created_at": "2026-01-01T00:00:00Z"
}
```

Allowed `rights_status` examples: `permission_confirmed`, `public_terms_reviewed`, `user_supplied_review_required`, `restricted`, `unknown`. These labels are internal workflow values, not legal conclusions.

## 3. Passage / chunk

```json
{
  "passage_id": "pas_example",
  "source_id": "src_example",
  "subject_id": "science",
  "chapter_id": "science_chapter_01",
  "chapter_title": "Chapter title from confirmed edition",
  "language": "en",
  "pdf_page_index": 12,
  "printed_page_label": "13",
  "section_heading": "Section heading if available",
  "text": "Extracted passage text",
  "extraction_method": "pymupdf",
  "extraction_quality": "reviewed",
  "content_hash": "hash of normalized passage text",
  "embedding_model": "configured model identifier",
  "index_version": "index-version-id"
}
```

Suggested `extraction_method` values: `pymupdf`, `ocr`, `manual`. Suggested `extraction_quality` values: `unreviewed`, `reviewed`, `low_quality`, `rejected`.

## 4. Question

```json
{
  "question_id": "q_example",
  "subject_id": "science",
  "source_id": "src_example",
  "chapter_id": "science_chapter_01",
  "chapter_title": "Chapter title",
  "language": "en",
  "origin": "ai_generated",
  "question_type": "mcq",
  "question_text": "Question text",
  "options": [
    {"option_id": "A", "text": "Option A"},
    {"option_id": "B", "text": "Option B"},
    {"option_id": "C", "text": "Option C"},
    {"option_id": "D", "text": "Option D"}
  ],
  "correct_option_id": "B",
  "explanation": "Short source-aligned explanation",
  "source_refs": [
    {
      "passage_id": "pas_example",
      "pdf_page_index": 12,
      "printed_page_label": "13"
    }
  ],
  "difficulty": "medium",
  "review_status": "pending_review",
  "review_notes": null,
  "reviewed_by": null,
  "reviewed_at": null,
  "model_provider": "groq",
  "model_id": "configured-model-id",
  "prompt_version": "mcq-v1",
  "content_version": 1,
  "created_at": "2026-01-01T00:00:00Z",
  "updated_at": "2026-01-01T00:00:00Z"
}
```

### Enumerations
- `origin`: `textbook`, `adapted`, `ai_generated`.
- `question_type`: `mcq`, `true_false`, `fill_blank`, `short_one_mark`.
- `difficulty`: `easy`, `medium`, `hard`, `unknown`.
- `review_status`: `draft`, `pending_review`, `verified`, `rejected`, `retired`.
- `language`: BCP-47-style language code such as `en`; add others only after language QA.

### Question validation rules
- For `mcq`, require four non-empty options for the initial app and one valid `correct_option_id`.
- Option IDs must be unique.
- Option text must not be duplicate after normalization.
- The correct answer must be supported by source references.
- Every verified textbook-grounded question must reference a known source and valid passage/page.
- A question cannot be `verified` merely because it is valid JSON or has been generated by an LLM.
- `textbook` questions should preserve wording only where permitted and accurately extracted.
- If the source is ambiguous or OCR quality is poor, keep the question pending or reject it.
- Store a change history or immutable revision when the correct answer or source changes.

## 5. Chapter

```json
{
  "chapter_id": "science_chapter_01",
  "source_id": "src_example",
  "subject_id": "science",
  "chapter_number": 1,
  "title": "Exact title from the selected textbook edition",
  "start_pdf_page": 1,
  "end_pdf_page": 24,
  "status": "reviewed"
}
```

Chapter page ranges are edition-specific and must be confirmed during ingestion.

## 6. Student attempt

```json
{
  "attempt_id": "attempt_example",
  "local_student_id": "anonymous-local-id",
  "question_id": "q_example",
  "selected_option_id": "A",
  "is_correct": false,
  "mode": "practice",
  "attempted_at": "2026-01-01T00:00:00Z",
  "question_content_version": 1
}
```

Use a random local identifier rather than a real name when possible. The MVP should not require an account. Define retention and sync rules before collecting or uploading progress.

## 7. Generation job

```json
{
  "job_id": "job_example",
  "subject_id": "science",
  "source_id": "src_example",
  "chapter_id": "science_chapter_01",
  "requested_count": 20,
  "status": "pending",
  "retrieved_passage_ids": ["pas_example"],
  "model_provider": "groq",
  "model_id": "configured-model-id",
  "prompt_version": "mcq-v1",
  "candidate_question_ids": [],
  "validation_summary": {},
  "created_at": "2026-01-01T00:00:00Z",
  "completed_at": null
}
```

Possible job states: `pending`, `running`, `completed`, `failed`, `cancelled`. Protect generation-job endpoints.

## 8. Textbook Q&A response

```json
{
  "answer": "Answer grounded in the selected textbook passages.",
  "abstained": false,
  "source_refs": [
    {
      "passage_id": "pas_example",
      "chapter_title": "Chapter title",
      "pdf_page_index": 12,
      "printed_page_label": "13"
    }
  ],
  "model_id": "configured-model-id",
  "prompt_version": "qa-v1"
}
```

If evidence is insufficient, set `abstained` to `true`, explain that the selected textbook content did not provide enough evidence, and return no fabricated citation.

## 9. API conventions
- Use stable IDs rather than array positions as identifiers.
- Return explicit schema/version information for long-lived cached content.
- Return validation errors with safe, useful messages.
- Do not expose internal secrets, private raw files, or unrestricted admin data.
- Do not trust `is_correct` values submitted by clients if the server later becomes authoritative for scoring.
